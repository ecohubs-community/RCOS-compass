## ADDED Requirements

### Requirement: Core work outranks module work, visibly and by a weight a community can change

Where a community has adopted modules, the ordering MUST rank core items above
module items by default, because core compliance is the gate. The rule MUST be a
weight shown and editable like every other input, not a hidden rule.

#### Scenario: A community with a module
- **WHEN** the path is read
- **THEN** core items rank above module items of otherwise equal standing

#### Scenario: The weight is shown
- **WHEN** a member reads why an item is where it is
- **THEN** the standard it belongs to is among the stated reasons

#### Scenario: A community disagrees
- **WHEN** a steward changes the weight
- **THEN** the ordering changes accordingly, and the change is recorded like any other
